# 乳首当てゲーム（仮）

超ダンディな筋肉紳士を相手に、ピチピチのシャツの上から隠された「一点」を探し当てるミニゲームです。

## ゲーム概要

- **TIME ATTACK（5ラウンド制）**  
  制限時間内にポイントを探し出し、タイミングメーターの往復回数が少ないうちにロックオンを決めるスピード勝負です。
- **CHALLENGE（無限サドンデス）**  
  制限時間内に連続成功を目指すモード（NORMAL / HARD / DEATH）。5連続成功ごとに1/2の確率で「DANDY FEVER（スコア2倍）」が発動します。

## 遊び方

1. 画面上のキャラクターの胸元を指やマウスでなぞります。
2. ポイントとの距離に応じて、キャラクターの表情・セリフ・鼓動音が変化します。
3. 「ここだ！」と思ったらロックオンボタンを押し、タイミングバーを赤いゾーンで止めて得点を獲得します。
